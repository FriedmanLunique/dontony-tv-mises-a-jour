# Don Tony IPTV — mises à jour de l'appli télé

Ce dépôt sert uniquement à distribuer les mises à jour de l'appli Android TV « Don Tony IPTV ».

- `version.json` : dernière version disponible, lue par l'appli.
- Les fichiers APK sont dans l'onglet **Releases**.

L'appli ne contient aucun contenu : c'est un simple lecteur, il faut son propre abonnement.
